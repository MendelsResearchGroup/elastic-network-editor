# Reliable network simulations

Compression measurements start at the relaxed cell immediately before loading. Heating displays temperature and area. Pausing and resuming preserves the trajectory. Closing or replacing a run safely releases it.

Drawn springs use their own geometric rest lengths. Imported harmonic networks retain the simulation cell, spring rest lengths and explicit angular interactions through editing and local saving. Unsupported models produce a visible import error. A graph without bonds stays editable.
